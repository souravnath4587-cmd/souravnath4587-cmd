## 🎯 About Me

> 💻 I'm a **MERN Stack Developer** who has built and deployed **three full-stack web applications**: a food delivery platform, a recipe-sharing community and a pet adoption site. They feature Firebase authentication, role-based admin dashboards, real-time tracking and REST APIs. I'm comfortable with **React** and **Next.js** on the front end and **Node.js**, **Express** and **MongoDB** on the back end, and I'm looking for a **junior developer role** where I can ship production features and keep growing.

## 🛠️ Current Activities

- 🚀 Building and deploying full-stack apps with **Next.js**, **Express** and **MongoDB**.
- ⚡ Exploring real-time features with **Socket.io** and scalable API design.
- 💼 Actively looking for **junior developer** and **internship** opportunities.

<br />

### 🚀 Technical Expertise

- 🎨 **Frontend:** Building responsive, component-based UIs with **React**, **Next.js**, **TypeScript** and **Tailwind CSS**, tested across mobile, tablet and desktop.
- ⚙️ **Backend:** Designing **REST APIs** with **Node.js** and **Express.js**, backed by **MongoDB**.
- 🔐 **Auth & Access Control:** Implementing **Firebase Authentication** and role-based access for users and admins.
- 🔄 **Real-Time Features:** Live order tracking and logistics using **Socket.io**.
